# Handoff audit checklist

| Área | Pergunta | Severidade se ausente |
|---|---|---|
| Identidade | O agente existe no registry e a versão do prompt está registrada? | alta |
| Contrato | Handoff e gate validam os JSON Schemas? | alta |
| Evidência | Cada critério aponta para resultado reproduzível? | alta |
| Independência | Autor, revisor e aprovador estão separados quando necessário? | alta |
| Rastreabilidade | O artefato liga entrada, decisão, código, teste e release? | média |
| Segurança | Dados sensíveis, ferramentas e exceções têm controle? | crítica |
| Observabilidade | Há trace, custo, latência e versão para reproduzir? | média |
| Expiração | Aprovação tem validade e condição de reavaliação? | média |
